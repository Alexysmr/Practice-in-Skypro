# Project_1

**Описание**
Курсовая работа "Проект 1. Приложение для анализа банковских операций" по специальности "Разработчик Python"
университета Sky Pro.
На момент составления данного документа программа содержит 4 модуля для обработки данных пользователей в банковской
сфере.

**Структура**

`src\utils.py` - модуль: обработки данных из файла формата XLSX; интерактивного запроса-получения от пользователя 
параметров для составления отчёта; запроса-получения курса валют и курса акций через API;  
`src\views.py` - модуль выполнения задания "События" в категории "Веб-страницы" - составление отчета в соответствии 
с полученными от пользователя параметрами;   
`src\services.py` - модуль выполнения задания "Простой поиск" в категории "Сервисы"  
`src\reports.py` - модуль выполнения задания "Траты по категории" в категории "Отчеты"  

**Инструкция по установке**

Для пользователя:

`poetry install --no-dev`

Для разработчика:

`poetry install`

**Зависимости:**

python 3.12.4  
requests 2.32.3  
python-dotenv 1.0.1  
pandas 2.2.2
pytest 8.2.2  
pytest-cov 5.0.0

**Запуск программы:**

`python main.py`

**Тестирование**

Тестовые модули :

`tests\test_views.py`   
`tests\test_reports.py`  
`tasts\test_services.py`  
`tests\test_utils.py`
